# Arabic voice dictation test

A standalone test page for live speech-to-text. You speak Arabic and see the words appear in the text box while you talk, then review and send. It also has an optional auto-send on stop.

It is a trial before adding the same control to the Najm supervisor chat in the Kawkab admin panel.

- The page stores nothing and sends nothing anywhere. Its "send" only places the text in the on-page demo conversation.
- Speech is recognised by the device's own dictation service: Apple on iPhone, Google in Chrome.
